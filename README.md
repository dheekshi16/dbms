# K.G. College of Arts and Science - Admission Portal

A DBMS Mini-Project featuring a premium Admission Form and Admin Dashboard using **Node.js** and **SQLite**.

## 🚀 Features
- **Modern UI**: Glassmorphism design with smooth animations.
- **Admission Form**: Captures student details (Name, Course, GPA, etc.).
- **Admin Dashboard**: Real-time view of all submitted applications.
- **Database**: Zero-config **SQLite** database (`college_admission.db`).
- **REST API**: built with Express.js.

## 🛠️ Prerequisites
- **Node.js** (Installed on your system)

## 📦 Installation
1.  **Clone or Download** this repository.
2.  Open the terminal in the project folder.
3.  Install dependencies:
    ```bash
    npm install
    ```

## ▶️ How to Run
1.  Start the server:
    ```bash
    node server.js
    ```
2.  Open your browser:
    - **Home Page**: [http://localhost:3000](http://localhost:3000)
    - **Admission Form**: [http://localhost:3000/form.html](http://localhost:3000/form.html)
    - **Admin Dashboard**: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## 🗃️ Database Info
- The data is stored in `college_admission.db`.
- You can view the data via the **Admin Dashboard** or any SQLite Viewer.
